# ALHAJ TV — بداية مشروع أندرويد

هذه نسخة أولية لواجهة Flutter، وليست تطبيق بث مكتمل بعد.

## المتطلبات
- Flutter SDK
- Android Studio أو VS Code
- Android SDK

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `alhaj_tv` في الطرفية.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
4. لإنشاء APK تجريبي:
   ```bash
   flutter build apk --release
   ```
   ستجد الملف غالباً في `build/app/outputs/flutter-apk/app-release.apk`.

## ما الموجود حالياً؟
- واجهة عربية داكنة بلمسات ذهبية.
- بحث محلي تجريبي.
- تصنيفات قابلة للاختيار.
- بطاقات محتوى تجريبية.
- شريط تنقل سفلي.

## ما الذي يحتاج إلى تطوير قبل الاستخدام؟
- خادم خلفي وقاعدة بيانات لإدارة المحتوى.
- لوحة تحكم محمية بتسجيل دخول.
- مصادر بث قانونية تملك حق استخدامها.
- مشغل فيديو يدعم الروابط المرخصة والجودات المتاحة.
- ترجمة، سجل متابعة، ومفضلة مرتبطة بحسابك.

لا توجد أفلام أو روابط بث مضمّنة في هذا النموذج.
